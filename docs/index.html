ViralClips

Turn long videos into captioned vertical clips, ready to post.

Full Cut runs 100% in your browser. Cut using AI sends only analysis data — your video file is never uploaded.

No score can guarantee a clip will go viral. ViralClips only ranks the moments most likely to hold a stranger's attention.

Honest note: a static page cannot download YouTube or TikTok videos directly — the browser blocks it. ViralClips tries a public download service first. If that fails, upload the video file below instead — that path works fully in your browser.

Drop a video file here, or click to choose one

MP4, WebM, MOV and most other video files. The file never leaves your computer.

Optional: paste a transcript (helps hook + keyword scoring and captions)

In-browser transcription is limited: the Web Speech API listens through the microphone, not through a video file, so there is no reliable way for a static page to transcribe a file by itself. Pasting a transcript is the reliable way to get word-based scoring and captions here.

Experimental: plays the video and listens through your microphone. Only works in Chrome/Edge, and only if your speakers are audible to the mic. Results appear in the transcript box above.

      • Only clip videos you made yourself, or videos you have permission to use. You are responsible for the rights to what you download, clip and post, and for following YouTube / TikTok terms.

      • Your video file never leaves your computer. In Cut using AI mode, only analysis data (timestamps, loudness, transcript) is sent to our own server so Muse can rank the moments — no video bytes, and no key from you is needed.
